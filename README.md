# GrantCrafter Landing Page

Official marketing website for [GrantCrafter.org](https://grantcrafter.org) — The AI-powered grant discovery and proposal copilot platform for NGOs, associations, and companies.

## Overview
- **Production Domain**: `https://grantcrafter.org`
- **Application Portal**: `https://app.grantcrafter.org`
- **Hosting**: Cloudflare Pages

## Tech Stack
- Static site / Frontend framework
- Tailwind CSS
- Cloudflare Pages Deployment

## Local Development
```bash
# Install dependencies
npm install

# Start local dev server

# Build for production
