Support

Help centre

Start with the right call, keep applicant evidence reusable, and move through each proposal step in order.

Getting started

Create an organisation, complete its applicant dossier, then find a live opportunity or import an external call. GrantCrafter uses that dossier—not the account owner’s identity—through eligibility and drafting.

Discovery and alerts

Use filters to find current calls, save useful opportunities to Favourites, and create funding alerts by country and thematic area.

Eligibility and proposal drafting

Review the extracted donor requirements, complete missing applicant evidence, assess eligibility, and then build the concept, analyses, Theory of Change, logical framework, technical narrative, workplan and budget.

Exports

Pro workspaces can export the proposal as Word or PDF and create an editable donor pitch deck in PowerPoint.

Need support?

Use the contact form or email support@grantcrafter.org.
